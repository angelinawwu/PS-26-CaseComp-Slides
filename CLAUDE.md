# Working rules

## Commit continuously
- Commit after every meaningful edit (a slide changed, a component added, copy revised) — don't batch a session's work into one commit at the end.
- Keep each commit small and scoped, with a message that says what changed (e.g. `Slide 4: tighten market-size copy`).
- Never leave the working tree with uncommitted changes at the end of a turn.
